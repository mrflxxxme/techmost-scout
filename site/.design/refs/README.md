# Разведка среды, 27.08.2026

Восемнадцать сайтов среды (deep tech, промышленный хардвер, научно-технический
консалтинг, кириллическая типографика). Параметры сняты не с кадров и не по
памяти: забран живой HTML и подключённый CSS каждого сайта и разобран.

| Файл | Что |
|---|---|
| `sites.json` | список источников с ролью каждого в выборке |
| `live-params.json` | гарнитуры (Google Fonts, `@font-face`, объявления), фоны по частоте, сигнальные цвета, CSS-переменные, `theme-color` |
| `live-nav.json` | модель шапки: число пунктов, бургер, липкость, подписи |

Скриншотов нет намеренно: Chromium в этой среде наружу не выпускается, соединение
рвётся и с прокси, и без него. Поэтому в борде на каждой плитке стоит живая ссылка —
по правилу «решение принимается по живому, а не по кадру» это и так страховка,
а не удобство.

## Четыре находки

1. **Среда живёт на светлом.** 15 из 18 построены на светлой тёплой базе
   (`#F6F7F4` Impulse, `#FCFCF8` и `#F5F5EF` Deep Science Ventures, `#F0EEE6`
   Helion). Тёмное берут секциями. Единственный тёмный целиком — Commonwealth Fusion.
2. **Тёплый акцент звучит на холодном фоне.** Терракота `#CF6D46` на тёмно-синем
   `#152536` у Commonwealth Fusion; оранжевый `#FF9900` на нейтральном `#191919`
   у Machina Labs. Тёплый акцент на тёплом тёмном фоне не встречается ни разу —
   получается грязь. Круг 4 этого прогона наступил ровно на эти грабли.
3. **Гротеск и свой моноширинный из одной словолитни.** Söhne + Söhne Mono,
   NB International + Mono, ABC Monument Grotesk + Mono, Applied Sans + Applied Mono,
   Roboto + Roboto Mono. Дисплейных шрифтов с засечками в выборке ноль.
   Кириллический эквивалент паттерна: **Martian Grotesk + Martian Mono**, OFL,
   бесплатно. Кириллица проверена живьём по д, з, к, ъ, я, ж, щ — все на месте.
4. **Навигации почти нет.** Hadrian — один пункт «Menu». Applied Intuition — один
   «Join us». Anduril — ноль в шапке. Boom — три. Против них Cambridge Consultants —
   сорок шесть пунктов, Science Group — девять с телефонами в шапке. Это и есть
   граница между современной компанией и отраслевым сайтом.
