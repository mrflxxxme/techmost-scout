# Работа из удалённой среды

Что нужно, чтобы продолжить разработку не с домашней машины. Написано
оркестратором 21 августа 2026 по итогам подэтапа Э2-Г.

## Что уже готово и приезжает само

Вся методология команды агентов версионируется и лежит в репозитории:

| Что | Где |
|---|---|
| Шесть ролей (исполнитель, проверяющий, планировщик, интервьюер, аудитор, верификатор) | `.claude/agents/*.md` |
| Шесть команд `/team-*` | `.claude/commands/*.md` |
| Настройки среды разработки | `.claude/settings.json` |
| Конвенции команды и десять инвариантов | `docs/team/CONVENTIONS.md`, `docs/team/INVARIANTS.md` |
| Спецификация продукта | `docs/SPEC.md` |
| Планы, решения, доказательства, ворота трёх подэтапов | `.planning/` |

Ничего из этого не хранится вне репозитория — переносить руками нечего.

**Опубликовано** в приватный `github.com/mrflxxxme/techmost-scout`: `main`,
`session/E2B`, `session/E2V`, `session/E2G`. Ветки отдельных задач не
публиковались сознательно: их содержимое уже слито в ветки подэтапов, а восемь
десятков веток-обрубков только мешали бы читать историю.

## Что нужно внести руками — переменные окружения

Файл `.env` **не версионируется и версионироваться не должен** (инвариант №3).
В репозитории лежит только `.env.example` без значений. В удалённой среде
значения вносит владелец; ниже — что именно и что сломается без каждой.

### Без этого не работает ничего платного

| Переменная | Что даёт | Без неё |
|---|---|---|
| `DEEPSEEK_API_KEY` | основная модель, все восемь стадий (РЕШ-171: ГигаЧат выпилен из кода) | падает весь конвейер |
| `YANDEX_SEARCH_API_KEY` + `YANDEX_CATALOG_ID` | платный поиск по русскому вебу | нет веб-кандидатов и всего конкурсного класса |
| `ROSPATENT_API_KEY` | патенты Роспатента | нет патентных кандидатов (в воротном прогоне давали 20 из 147) |

### Полезно, но не блокирует

| Переменная | Что даёт | Без неё |
|---|---|---|
| `YANDEX_API_KEY` | аварийный резерв модели | при отказе DeepSeek стадия падает вместо перехода на резерв |
| `OPENALEX_API_KEY` | обогащение по DOI | поиск работает, цитируемость не добирается |
| `SEMANTICSCHOLAR_API_KEY` | повышенные лимиты | источник чаще отвечает отказом по лимиту |
| `PATENTSVIEW_API_KEY` | патенты США | адаптер помечен заготовкой, пока не используется |
| `CROSSREF_MAILTO` | вежливый пул Crossref | работает медленнее |

### Настройки поведения, не секреты

Их можно взять из `.env.example` как есть. Значения, принятые решениями и
важные для воспроизводимости:

```
COST_LIMIT_RUB_PER_REQUEST=20     # боевой стоп-кран на запрос (РЕШ-46)
LLM_STAGE_ROUTES=intake:deepseek,extractor:deepseek,planner:deepseek,replan:deepseek,scorer:deepseek,card_author:deepseek,verifier:deepseek,summary:deepseek
```

**`GOOGLE_API_KEY` и `GOOGLE_CSE_ID` вносить не нужно** — источник удалён
(РЕШ-174), настроек в `Settings` для него больше нет.

**`RELEVANCE_MIN` вносить не обязательно** — рабочее значение 3 (РЕШ-74,
порог снижен РЕШ-162) переехало в умолчание кода (РЕШ-174). Переменная нужна
только для переопределения при необходимости — например, при разборе нового
прогона калибровкой.

**`SECOND_PASS_RELEVANCE_MAX` вносить не обязательно** — рабочее значение 6
(РЕШ-103) переехало в умолчание кода (долг ворот Э2-Ж, закрыт задачей Д-3
волны Э2-З: та же болезнь, что и с `RELEVANCE_MIN`). Переменная нужна только
для переопределения при необходимости — например, чтобы временно выключить
второй проход значением 0 при разборе прогона.

## Проверка, что среда собрана верно

```bash
python -m app.cli doctor
```

Команда печатает по каждому ключу и каждому источнику, работает он или нет и
почему. С неё начинается разбор любой проблемы; ею же проверяется, что перенос
ключей прошёл успешно.

Затем — набор без сети:

```bash
python -m pytest -q
```

Ожидаемое — не меньше базовой линии текущей волны (см.
`.planning/evidence/E2J-baseline-pytest.txt`; на момент правки — 753 passed).
Точное число растёт с каждой волной и не переписывается здесь вручную. Тесты
изолированы от боевого окружения (задача З-1 подэтапа Э2-В): числа не
меняются от присутствия `.env` рядом, и в рабочую базу тесты не пишут.

## Две ловушки, стоившие нам денег и времени

**Чужой код в платном прогоне.** Пакет `app` установлен в виртуальное
окружение, и `python -m app.cli` без `PYTHONPATH` берёт его из главного дерева,
а не из рабочей копии подэтапа. Один платный прогон так и ушёл на код
предыдущего подэтапа — 6,88 ₽ впустую (РЕШ-105). **Перед каждым платным
запуском печатается `app.__file__`, и запуск отменяется, если путь не из
нужного дерева.**

**Прогон без ограничения по времени.** Каждый платный прогон запускается с
жёстким пределом и убийством процесса по превышению — иначе он висит и тратит
молча. Предел прогона 45 минут, дешёвой пробы — 5 минут. Замеры для ориентира:
обычный прогон 21–32 минуты и 8–11 ₽, прогон со вторым проходом 49,6 минуты и
13,4 ₽, проба интейка 54 секунды и 0,17 ₽.
