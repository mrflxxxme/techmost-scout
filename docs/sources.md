### Открытые данные Роспатента — работают без ключа

`rospatent.gov.ru/opendata` → 200. **28 наборов** на срез 05.08.2026, из них
**9 по интеллектуальной собственности**, все **CSV**, обновление **ежемесячно**
полным снимком (дельт нет, имя файла меняется каждый месяц).

| Набор | Записей ≈ | Объём |
|---|---|---|
| `-iz` изобретения | 776 000 | 695 120 416 Б (663 МиБ) |
| `-pm` полезные модели | 229 000 | 170 211 799 Б |
| `-evm` программы ЭВМ | 301 000 | 179 923 557 Б |
| `-bd` базы данных | 42 000 | 37 025 088 Б |
| `-po` промобразцы | 113 000 | 61 539 917 Б |
| `-tz` товарные знаки | 1 095 000 | 687 174 811 Б |
| Все 9 наборов ИС | — | **1,72 ГиБ** |
| Технически релевантное подмножество (`-iz`,`-pm`,`-evm`,`-bd`,`-tims`) | **1,35 млн** | **1,01 ГиБ** |

**Полнота полей — 46 полей у `-iz`:** номер, название (заполнено 98,8 %), даты,
заявка, авторы, патентообладатели, `actual`, `publication_url`.
**Реферата, формулы, описания и МПК нет ни в одном наборе.** Отсюда главное
следствие: открытые данные — точный **реестр**, а не поисковик по смыслу.

`robots.txt` → `Allow: /`, `/opendata` не запрещён, капчи нет: автоматическая
загрузка правил не нарушает. Ловушки загрузчика: UTF-8 с BOM, запятая,
переносы строк внутри кавычек (нужен настоящий CSV-парсер); файл структуры —
наоборот windows-1251 и точка с запятой.

**Оценка локального индекса:** SQLite + FTS5 по названию — **1,5–2,5 ГБ диска**
на релевантное подмножество, первичная загрузка **20–60 минут** машинного
времени, обновление — **полная перезаливка ~1 ГиБ ежемесячно**.

### Поисковая платформа `searchplatform.rospatent.gov.ru` — только по ключу

Все эндпоинты закрыты: `/patsearch/v0.2/search`, `/similar_search`, `/docs/{id}`,
`/user/register` → **401**. Сама платформа заявлена Роспатентом как
общедоступная и бесплатная, фонд «свыше 100 млн охранных документов».
Ключ — «только зарегистрированным пользователям, в разделе „Генерирование
ключей" пользовательского интерфейса» (документ «Открытые API ИС ПП»).

Даёт сверх открытых данных: рефераты, формулы, описания, **МПК**, цитирования,
запрос на естественном языке `qn` и **`similar_search` — поиск похожих по
фрагменту произвольного текста**. Это ровно операция скаутинга.

**Кому выдают, платно ли, сроки рассмотрения и лимиты запросов — НЕ
УСТАНОВЛЕНО:** публичной оферты и регламента не существует, проверены
`rospatent.gov.ru/ru/sourses`, `online.rospatent.gov.ru/open-data/open-api`
(SPA, содержимое внешнему чтению не отдаётся), новости Роспатента. Узнаётся
только изнутри личного кабинета после бесплатной регистрации.

### ФИПС — открылся; рефераты и МПК бесплатны, но обход запрещён robots.txt

**17.08.2026 из рабочей сети `www1.fips.ru`, `www.fips.ru`, `fips.ru`,
`new.fips.ru` → 200** (14 августа было 403 DDoS-Guard). Живы подсистемы:
ИПС `/iiss/` (JSF/PrimeFaces), открытые реестры `/registers-web/`, официальные
публикации `/publication-web/`. Собственного раздела открытых данных у ФИПС
нет: `/opendata/` → 404.

**Регистрация для бесплатных баз не нужна:** «вход в поисковую систему (ИПС)
осуществляется без ввода логина/пароля». Бесплатно доступны **рефераты
российских изобретений на русском и английском с 1994 г.**, формулы полезных
моделей, программы ЭВМ / БД / топологии ИМС с 2013 г., полные тексты за
последние 3 бюллетеня, МПК 2026.01, МКТУ, МКПО. Платно: полный архив текстов,
товарные знаки, промобразцы, документы 1924–1993; «единицей оплаты считается
один запрос».

**Ограничение, определяющее путь:** `www1.fips.ru/robots.txt` (695 строк
правил) для `User-agent: *` содержит `Disallow: /iiss/`,
`Disallow: /registers-web/`, `Disallow: /publication-web/`,
`Disallow: /publication-ws/`. Все три нужные подсистемы закрыты для
автоматического обхода. По аналогии с границей по Google (РЕШ-55) программный
обход не строим. **ФИПС остаётся ручным инструментом оператора**, а
программный канал к российским рефератам и МПК называется «поисковая
платформа».
