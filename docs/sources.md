# Разведка источников

Живой документ: сюда записываются результаты проверки каждого источника —
что отдаёт, какие лимиты, какие ловушки. Обновляется при работе над этапом 2.

## Проверено и работает (9 августа 2026)

| Источник | Статус | Заметки |
|---|---|---|
| Crossref | работает без ключа | Обязателен mailto в User-Agent (уже зашит). Русскоязычных журналов мало, но DOI-база лучшая |
| КиберЛенинка OAI-PMH | работает без ключа | `Identify` отвечает. ListRecords тяжёлый — кэш на диске обязателен (реализован). Полнотекстового поиска нет: фильтрация по словам локально |
| arXiv | работает без ключа | Лимит 1 запрос / 3 сек соблюдается адаптером. Русских прикладных работ мало — полезен для передовых тем |
| Semantic Scholar | работает, 429 без ключа | Общий пул. Свой ключ — по заявке (см. deps-manual.md, п. 5) |
| DeepSeek API | работает | **V4-Flash — рассуждающая модель**: тратит токены на reasoning_content до ответа. Провайдер обрабатывает пустой content; стадиям нужны щедрые max_tokens |
| GigaChat | **работает** | Рабочий адрес — `gigachat.devices.sberbank.ru/api/v1`. Разошедшийся по публикациям `api.giga.chat` отдаёт 403 от nginx — не верить. Требует бандл с сертификатами НУЦ Минцифры (`scripts/build_ca_bundle.py`). Доступные модели: GigaChat, GigaChat-2, GigaChat-2-Pro, GigaChat-2-Max |
| YandexGPT | ключ просрочен 30.06.2026 | Перевыпустить по deps-manual.md, п. 4. CLI `yc` не помогает: Яндекс не принимает к обмену OAuth-токены, выданные после 01.06.2026 |

## Предстоит разведать (этап 2)

- **Открытые данные Роспатента** (rospatent.gov.ru/opendata): форматы, полнота,
  частота обновления. Поисковая платформа searchplatform.rospatent.gov.ru — по ключу.
- **ЕГИСУ НИОКР (rosrid.ru)**: API нет, гостевой поиск урезан, полный доступ —
  только по регистрации организации. Вернуться после появления юрлица.
- **РНФ / Фонд содействия инновациям**: открытых данных нет, только HTML —
  ходить через Яндекс-поиск с операторами site: (этап Э2-3).
- **OpenAlex snapshot** (S3, CC0, бесплатно): кандидат на локальный индекс в
  версии 2 — див. бэклог.
