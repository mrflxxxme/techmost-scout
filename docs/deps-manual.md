# Что нужно донести вручную

Перечень внешних зависимостей, которые не может закрыть ИИ-агент: везде нужны
ваши персональные данные, согласие с условиями или оплата. Всё остальное
(код, промпты, конфигурация, бесплатные источники без регистрации) уже в
репозитории или делается агентами по спецификации.

Статус на 9 августа 2026. После каждого пункта — как проверить: `scout doctor`
показывает результат по каждому ключу и источнику.

## Обязательно до первого боевого запроса

### 1. GigaChat — основная модель (бесплатно) — ✅ ключ перенесён

Ключ перенесён из TEAMLY_RU и лежит в `.env`. Осталось одно: **корневой
сертификат НУЦ Минцифры**. Домены Сбера подписаны им, и без него проверка TLS
падает (это видно в `scout doctor` как `CERTIFICATE_VERIFY_FAILED`).

Что сделать (один раз, ~5 минут):
1. Скачать «Сертификаты для Windows» с https://www.gosuslugi.ru/crt — файл
   корневого сертификата (russian_trusted_root_ca.cer) и выпускающего
   (russian_trusted_sub_ca.cer).
2. Сложить их в один файл-бандл в формате PEM, добавив к стандартному certifi:
   ```powershell
   .\.venv\Scripts\python.exe -c "import certifi, shutil; shutil.copy(certifi.where(), 'data/ru_bundle.pem')"
   # затем дописать в конец data/ru_bundle.pem содержимое обоих .cer в PEM-виде
   ```
3. В `.env` указать: `GIGACHAT_CA_BUNDLE=data/ru_bundle.pem`
4. Проверить: `scout doctor` → gigachat «ок».

Обходной путь только для локальной отладки: `GIGACHAT_VERIFY_SSL=false`.
На сервере так нельзя.

Если ключ протухнет: developers.sber.ru → проект GigaChat API → новый ключ
авторизации. Вход по Сбер ID. Бесплатный тариф — 250 млн токенов Lite на год.

### 2. DeepSeek — качественные стадии — ✅ работает

Ключ перенесён, `scout doctor` показывает «ок» (0.0017 ₽ за проверочный вызов).
Следить за одним: **баланс**. Пополнение — только зарубежной картой или через
посредника. При нуле баланса система продолжит работать: стадии уйдут на
GigaChat по резервному маршруту, качество карточек просядет, но не упадёт.

### 3. YandexGPT — аварийный резерв — ⚠️ ключ просрочен

`scout doctor` показывает: «apikey has expired 2026-06-30». Ключ из TEAMLY_RU
умер. Если резерв нужен (рекомендую, но не срочно):
консоль Yandex Cloud → сервисный аккаунт → роль `ai.languageModels.user` →
новый API-ключ → значение в `YANDEX_API_KEY` в `.env`. `YANDEX_CATALOG_ID`

Без этого ключа система полностью работоспособна на двух провайдерах.

## Желательно в первые две недели (этапы 2–3)

### 4. OpenAlex — обогащение карточек по DOI

С 13.02.2026 ключ обязателен. Бесплатно и быстро: openalex.org/settings/api
(~30 секунд, без карты). Значение → `OPENALEX_API_KEY`. Используется только
для бесплатных lookup по DOI — поиск у них платный, мы им не пользуемся.

### 5. Semantic Scholar — свой ключ вместо общего пула

Сейчас источник работает без ключа, но на общем лимите — в час пик отдаёт 429
(видно в doctor). Заявка: semanticscholar.org/product/api, форма, ключ приходит
на почту (дни–недели). Значение → `SEMANTICSCHOLAR_API_KEY`.
Нюанс: ключ отзывают после ~60 дней неактивности.

### 6. htmx.min.js — один файл для интерфейса (этап 3)

Агенты не тянут бинарники из сети. Скачайте https://unpkg.com/htmx.org@2/dist/htmx.min.js
и положите в `backend/app/web/static/htmx.min.js`.

### 7. Приватный репозиторий на GitHub

## По необходимости (когда дойдут руки или деньги)

### 8. Yandex Search API — поиск по сайтам институтов и грантам

Единственный платный источник (≈50–200 ₽ за 1000 запросов; в пайплайне жёсткий
лимит 6 запросов на прогон). Бесплатной замены нет: у Brave бесплатный тариф
закрыт в 02.2026. Нужен биллинг-аккаунт Yandex Cloud с картой → API-ключ →
`YANDEX_SEARCH_API_KEY`. В TEAMLY_RU этого ключа не было.

### 9. PatentsView — патенты США

Бесплатный ключ по заявке в service desk PatentsView (patentsview.org →
API → Request API Key). Значение → `PATENTSVIEW_API_KEY`. Нужен, только если
хотим проверять мировую патентную чистоту, а не только РФ.

### 10. VPS и домен — к этапу 5

Любой российский провайдер, 2 ГБ памяти достаточно (~500–1500 ₽/мес) + домен.
Дальше по `docs/deploy.md` (появится в этапе Э5-1).

### 11. Витрина партнёров — данные, а не ключ

CSV с разработками институтов (этап 0.3 дорожной карты компании):
колонки `title, org, contact, maturity_stage, description, tags, url, source_note`.
Загрузка: `scout showcase файл.csv`. Это ваш приоритетный слой выдачи —
чем раньше появится, тем убедительнее отчёты.

### 12. Три реальных задачи для приёмки

Из проблемных интервью Фазы 0 — по одной на отрасль (нефтегаз, фарма,
агропром), обезличенные. Нужны к этапу Э5-2 вместе с валидатором (научный
со-основатель или сдельный эксперт).

  Роспатента — они работают без ключей, уже подключены.
- Покупать Perplexity/Anthropic для рантайма — при стратегии минимальной
  себестоимости они не используются (Claude остаётся инструментом разработки,
  а не частью продукта).
- Трогать Gemini, Groq, OpenRouter, Mistral — из РФ либо заблокированы, либо
  ненадёжны, либо требуют согласия на обучение на ваших данных.
- ЕГИСУ НИОКР (rosrid): API нет, гостевой поиск урезан, регистрация только для
  организаций — вернёмся, когда появится юрлицо.
