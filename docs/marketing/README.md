# Маркетинговые материалы «ТехМост»

Здесь лежат бизнес-документы компании: картина рынка, дорожная карта запуска,
сценарии проблемных интервью, питч-дек и исследования, на которых всё это
построено. Перенесены в репозиторий 22.08.2026 из рабочего каталога
`C:\Users\KUklonskiy\DBH\docs\rd-commercialization` (плюс пять исследовательских
отчётов и генератор дека, которые до этого жили только во временных каталогах
сессий).

**Это не требования к продукту.** Единственный источник требований к «ТехМост
Скаут» — [docs/SPEC.md](../SPEC.md), раздел 2а. Материалы этой папки описывают
компанию и рынок вокруг продукта.

Контакт во всех документах: Кирилл Уклонский · uklonskiy.k@gmail.com.

Сделан до появления слайда «Вопросы и возражения». Прежнее имя — `ТехМост (deck).pdf`. Для рассылки пересобрать заново из актуального pptx |
| [deck/gen-deck.js](deck/gen-deck.js) | Генератор дека на `pptxgenjs` (Node). Собирает 13 слайдов с нуля: чернильный фон с орбами, Segoe UI, карточки с двойной окантовкой, источники-гиперссылки у каждой цифры |
| [deck/add-faq-slide.py](deck/add-faq-slide.py) | Скрипт на `python-pptx`, добавивший 17.08.2026 слайд 13 «Вопросы и возражения» (6 карточек-возражений) перед финальным призывом и перенумеровавший футеры на «/ 14» |

Порядок пересборки: `node gen-deck.js` → получается 13-слайдовый файл → затем
`add-faq-slide.py` по нему → получается текущий 14-слайдовый. Оба скрипта
рассчитаны на запуск из каталога с исходным файлом, пути внутри проверьте перед
прогоном.
