# Московская область: ЗАО «Московская пивоваренная компания»

Трек — **Московская пивоваренная компания** (mosbrew.ru, Мытищи, 7 км от
МКАД). Предложение: оплачиваемый пилот «диагностика + подбор» под
технологическую задачу предприятия. Форма и посыл — по деку для Югорского
рыбоводного завода ([../hmao/](../hmao/)): боли подаются как вызовы отрасли,
цен в материалах нет (Р-25).

Главное про собеседника: по эффективности производства завод уже на верхнем
уровне отрасли (рекуперация тепла и CO₂, очистные дают 10% электроэнергии,
заявлена переработка 99% отходов). Разговор — не про оптимизацию цеха, а про
**сырьё и новые категории**: хмель, солод, дрожжи, безалкогольная линейка.

## Перед встречей проверить

1. **Применимость мер поддержки к производителю подакцизной продукции** —
   ПП-218 и повышающий коэффициент 2 по НИОКР стоят на слайде 8 общим
   блоком, но для пивовара не подтверждены (раздел 8 разведки). До
   подтверждения на словах — «подберём и посчитаем меры под конкретный
   проект».
2. **Адресат.** Дек оформлен на компанию. Если встреча персональная —
   гендиректор Дементьев Игорь Владимирович (с 2008 года), главный пивовар
   Михаил Ершов; плашка обложки меняется одной строкой в `gen-decks.js`.
3. **Факты с пометкой `[!]`** в разведке (численность, объём инвестиций,
   цифры по маркировке и хмелю от Минсельхоза) — на слайды не вынесены,
   сверить перед устным использованием.
4. **Третья карточка слайда «Команда»** — свердловский региональный партнёр;
   для подмосковного предприятия релевантность под вопросом. Решение
   владельца.

Пересборка: дек — `node ../../gov-deck/gen-decks.js`; справка —
`python3 ../../gov-deck/gen_onepagers.py`. PDF — LibreOffice
(`soffice --headless --convert-to pdf <файл>`); на машине без фирменных
шрифтов итоговые PDF для рассылки экспортируйте из PowerPoint/Word.
