# Свердловская область

Два трека:

1. **Правительство области / минпромнауки** — первый адресат компании
   (Р-11): через С. В. Пересторонина (советник губернатора) к А. В. Шмыкову
   (первый заместитель губернатора — министр промышленности и науки).
   Материалы — дек и справка «gov», разведка от 22.08.2026.
2. **Минприроды Свердловской области** — министерская встреча захода
   26.08.2026 (в паре с Югорским рыбоводным заводом — оба адресата ведёт
   один переговорщик, см. записку посреднику в
   [../../negotiation/note-broker-2026-08.md](../../negotiation/note-broker-2026-08.md)).
   Предложение: соглашение о сотрудничестве + представление
   предприятиям-природопользователям; расходов бюджета нет.
