# Журнал

Хронология проекта: что сделано, чем это подтверждено и какой урок из этого
следует. Пишет только оркестратор (§6 `docs/team/CONVENTIONS.md`), запись
добавляется после каждого этапа, задним числом не переписывается.

Формат записи — пять полей, все обязательны:

```markdown
## <дата> · <этап>

**Что сделано.** Результат, а не занятие.
**Чем подтверждено.** Фактический вывод команды или файл в
`.planning/evidence/`, а не «проверено».
**Урок.** Что мы теперь знаем и чего впредь не делаем.
```

Поле «урок» — не украшение: новый пункт `docs/team/INVARIANTS.md` добавляется
только после реального сбоя, и основанием служит запись из этого журнала.
Записи без урока не считаются закрытыми. Если этап прошёл без сбоев, урок
формулируется как подтверждённое ожидание — но пишется всё равно.

## 9–10 августа 2026 · Э1-1, перенос ключей и проверка окружения

**Что сделано.** Создан репозиторий `techmost-scout`, ветка `main`, приватная
публикация на GitHub. Собран скелет: контракты данных, настройки, модели БД, три
провайдера моделей с маршрутизатором и стоп-краном по цене, пять поисковых
адаптеров, семь стадий пайплайна с оркестратором, отчёт в markdown, командная
строка и веб-страницы. Ключи перенесены из TEAMLY_RU, бандл сертификатов НУЦ
Минцифры собран из хранилища Windows. Пайплайн заведён и проходит целиком: от
текста задачи до отчёта с карточками.

**Чем подтверждено.** Сквозной прогон `scout run` — 6 карточек, ~4 ₽ за запрос;
48 тестов проходят без сети; `ruff check` и `ruff format` чистые; `scout doctor`
показывает GigaChat и DeepSeek «ок», Crossref, arXiv и КиберЛенинку «ок».
Живые вызовы и их результаты сведены в `docs/SPEC.md`, раздел 0.1.

**Урок.** Промпты содержат метки подстановки вида `{{BRIEF_JSON}}`, и код их не
заполнял — модель получала метку текстом вместо данных. Дефект был почти
невидимым: карточки собирались, прогон не падал, и только проверяющая стадия
глухо писала «кандидаты не переданы» и занижала уверенность всем карточкам.
Отсюда два следствия. Первое: подстановки заполняются исключительно через
`render_prompt`, который падает при незаполненной метке, а состав меток
закреплён тестом (инвариант 4). Второе, более общее: работающий на вид результат
не является доказательством — сигналом считается только явная проверка, поэтому
пороги ворот требуют вывода команды, а не наблюдения «собралось».

## 10 августа 2026 · процесс работы команды агентов

**Что сделано.** Перенесены и сокращены конвенции проекта wizor: цикл из семи
шагов, шесть ролей в `.claude/agents/`, шесть команд запуска, шесть файлов
состояния, ворота с доказательствами. Проверяющим ролям запись запрещена
инструментально. Написан линтер конвенций `tests/test_team_docs.py`.

**Чем подтверждено.** 79 тестов проходят без сети, `ruff` чистый. Хук стартовой
сессии проверен фактическим запуском: печатает ветку, состояние и порядок чтения,
код возврата 0 как в репозитории, так и вне его. Линтер поймал невалидный YAML в
шапках четырёх ролей — они исправлены, повторная проверка чистая.

**Урок.** Двоеточие внутри незакавыченного значения ломает YAML, и это уже третий
случай в проекте: справочник господдержки, шапки команд, шапки ролей. Глазами
дефект не виден — текст выглядит нормально. Первая версия линтера его тоже
пропускала, потому что разбирала шапку по первому двоеточию вместо настоящего
парсера; ложное спокойствие от слабой проверки хуже отсутствия проверки. Отсюда:
шапки разбираются `yaml.safe_load`, а повторяющуюся правку делает
`scripts/fix_frontmatter_quotes.py`, а не руки. Общее следствие для команды:
проверяющий инструмент сам должен проверяться на заведомо плохом входе — новый
линтер прогнан на старой версии файла и подтверждённо её заваливает.

## 11 августа 2026 · закрытие внешнего контура ключей

**Что сделано.** Внешние зависимости закрыты полностью. Владелец перевыпустил
ключ YandexGPT взамен просроченного и очистил мёртвый IAM-токен, получил ключ
OpenAlex и отдельный ключ Yandex Search API, подал заявку на Semantic Scholar.
Приняты два решения, меняющие подход к данным: витрина партнёров наполняется
органически (РЕШ-11), задачи для приёмки берутся с рынка, а не из проблемных
интервью (РЕШ-12). Последнее снимает единственную блокировку с этапа Э1-2.

**Чем подтверждено.** `scout doctor` показывает все три модели «ок»: gigachat
0.0012 ₽, deepseek 0.0048 ₽, yandex 0.0036 ₽; шесть ключей «есть». Отдельно
живыми вызовами мимо доктора: OpenAlex вернул карточку работы по DOI
10.1038/nature12373; Yandex Search API создал асинхронную операцию, результат
раскодирован из base64-XML и содержит три реальные страницы центров трансфера
технологий. Semantic Scholar отдал 429 и был корректно пропущен — прогон при
этом не пострадал.

**Урок.** Два подтверждения и одна новая грабля. Подтвердилось правило «не
доверять публикациям, доверять живому вызову»: доктор рапортовал «ключ есть» по
факту непустой переменной, тогда как ключ Яндекса был мёртв уже полтора месяца —
наличие значения не равно работоспособности, и здоровье проверяется только
вызовом. Новая грабля этой машины: Git Bash отдаёт кириллицу в cp1251, и запрос
к Yandex Search с русским текстом из оболочки вернул 400 «non UTF-8 code
points», хотя ключ был исправен — сначала проверяем кодировку канала, потом
подозреваем ключ. Отсюда же: вывод `scout doctor` содержит знак рубля, который
консоль в cp1251 напечатать не может и падает с `UnicodeEncodeError` уже после
всех проверок — доктор запускается с `PYTHONIOENCODING=utf-8`.
