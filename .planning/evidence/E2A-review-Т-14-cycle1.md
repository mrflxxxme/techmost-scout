## Пробы, а не чтение

**1. Инвариант №5 в редакции РЕШ-43.** Семь путей отказа поднимают
`SearchError`: 401, 403, 429, 500, транспортный (`httpx.ConnectError`),
нечитаемое тело (200 + не-JSON). Все прогнаны, зелёные.

Дополнительно живой пробой: 200 с валидным JSON-объектом **без ключа `hits`
вообще** — `search()` отдаёт `[]` с `log.warning`, исключения нет. Ревьюер
сверил с `crossref.py` (не тронут дельтой, закреплено РЕШ-45) — там тот же
образец. Не отклонение этой задачи, отнесено советом.

**2. Инвариант №3.** Тест явно проверяет `"test-key" not in str(failure.value)`.
В сообщениях об ошибках — только имя переменной `ROSPATENT_API_KEY`, значение
не попадает никуда.

**3. `raw_id` не даёт склейки в `dedup_key`.** Проба: два ответа с одинаковым
`document_number = "2020130881"` и разными ведомствами:

```
WO2020130881A1 -> wo2020130881a1
RU2020130881A1 -> ru2020130881a1
```

Ключи разные, коллизии нет. Обоснование исполнителя подтверждено.

**4. Снятие `<em>` и HTML-сущностей** — прямой пробой `_strip_markup`:

| Вход | Выход |
|---|---|
| `<em>nested <b>tag</b> inside</em>` | `nested tag inside` |
| `unclosed <em>tag without close` | `unclosed tag without close` (текст цел) |
| `&amp; &lt;tag&gt; &quot;quoted&quot;` | `& <tag> "quoted"` |
| текст без разметки | не меняется |
| `None` / `""` | `""` |

Порядок операций верный: сначала снимаются реальные теги, потом раскрываются
сущности — декодированный `<tag>` не режется повторно.

**5. Темп — не декорация.** Ревьюер собрал мутанта на копии вне репозитория
(`min_interval_seconds` 1.0 → 0.0) и прогнал тест против неё:

```
test_темп_не_чаще_одного_запроса_в_секунду  УПАЛ
AssertionError: assert 0.0 >= 1.0
```

**6. `org` при пустом `applicant`.** Запись без `applicant` ни в `ru`, ни в
`en`, ни в `snippet`: кандидат собран без падения, `org = None`, название взято
корректно. Отбрасывается поле, а не карточка.

**7. Правка `tests/test_openalex.py` (5 строк)** — замена ожидания
`STATUS_STUB` → `STATUS_NO_KEY` с проверкой упоминания `ROSPATENT_API_KEY`.
Прямое следствие смены `implemented` с `False` на `True`, чужого поведения не
задевает.
