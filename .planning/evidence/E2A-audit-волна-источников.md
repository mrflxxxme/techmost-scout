## Блокирующее Б-2 — стоимость поиска OpenAlex

Аудитор: `openalex.py` после Т-15 утверждает «поиск бесплатен», а нетронутая
запись `config.py:89-90` в том же дереве — «с 13.02.2026 ключ обязателен, поиск
$1/1000 вызовов, держим только для обогащения по DOI». Поиск при этом уходит
**без заголовка `Authorization`**. Одна из записей ложна, счётчика нет.

**Факт установлен пробой оркестратора** — анонимный запрос, как в адаптере:

```
код ответа 200, БЕЗ ключа, только mailto
X-RateLimit-Cost-USD:        0.001    ← запрос стоил $0,001
X-RateLimit-Limit-USD:       0.1      ← дневная бесплатная норма $0,10
X-RateLimit-Remaining-USD:   0.099
X-RateLimit-Reset:           37536
найдено: «ОПТИМИЗАЦИИ УСТАНОВКИ ГИДРООЧИСТКИ ДИЗЕЛЬНОГО ТОПЛИВА ТОО „ПНХЗ"», 2023
```

Запись **наполовину устарела**: «ключ обязателен» — неправда; «$1 за 1000
вызовов» — правда. Расход ≈ 0,2 ₽ на прогон при стоп-кране 20 ₽.

**Снято решением владельца РЕШ-72:** РЕШ-10 отменён (опирался на два ложных
допущения — что нужен ключ и что поиск дублирует Crossref), счётчик заведён в
Т-18, документация приведена к факту.
