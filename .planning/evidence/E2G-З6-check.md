## Советы (не блокируют)

1. Раз реальный фарма-дубль (карточки 3 и 4) не ловится ни одним из четырёх
   условий на подлинных данных, стоит рассмотреть более мягкий сигнал — вроде
   пересечения по DOI/патентному номеру, извлечённому по регэкспу прямо из
   URL (doi.org/10.3390/...), а не только из raw_id адаптера; это отдельная
   находка для обсуждения с владельцем, не для тихой правки в эту задачу.
2. merge_duplicate_groups — O(n^2) по группам; при реальных объёмах выдачи
   (5-7 карточек) это не имеет значения, упомянуто на будущее, если объём
   вырастет.
