# Замер EPO DOCDB: покрытие и рефераты (одобрен владельцем, 170 МБ)

Выполнен оркестратором 14 августа 2026 по РЕШ-55 п. 2: «первый замер только на
170 МБ недельных, чтобы не тянуть всё сразу». Скачана одна недельная поставка
без единого ключа. Цель — ответить на вопрос, который разведка оставила
открытым: **есть ли в DOCDB рефераты, на каких языках и как там представлена
Россия.**

## Что скачано

```
Продукт:  14.7 EPO worldwide bibliographic data (DOCDB) — front file (id=3)
Поставка: 2026/033 Cr-Del, опубликована 2026-08-13T09:00
Файлы:    docdb_xml_202633_CreateDelete_001.zip   167 478 540 байт
          Front-file_Bibliographic_Coherence_2026_32.csv   2,1 МБ
Загрузка: без авторизации, публичный путь /api/public/products/...
```

## Формат: вложенные архивы по странам

Первый разбор дал **ноль документов** — и это была ошибка разбора, а не
свойство данных. Внутри архива не плоский XML, а структура:

```
docdb_xml_202633_CreateDelete_001/Root/
  VOLUMEID, CONTENTS, index.xml
  DOC/statistics_...csv, data_coverage_...csv
  DOC/DOCDB-202633-CreateDelete-PubDate20260807AndBefore-<СТРАНА>-0001.zip   × 50
  DTDS/
```

**Страна вынесена в имя вложенного архива** — это позволяет качать и разбирать
выборочно, не трогая всё. Внутри вложенного архива — XML с элементами
`exchange-document`.

Вторая грабля: XML использует DTD-сущности (`&mdash;` и подобные), и штатный
`xml.etree` падает с `undefined entity`. Лечится предобработкой или подключением
DTD из `Root/DTDS/`. Для загрузчика это обязательный пункт, не мелочь.

## Главный вывод: DOCDB не закрывает Россию

**В недельной поставке ровно один российский документ** — против 95 тысяч
китайских, 7,8 тысяч американских и 7,3 тысяч европейских. Это не погрешность
выборки: RU-архив внутри поставки весит 1 097 байт при 15 мегабайтах у одного
китайского тома.

Отсюда прямое следствие для плана: **вариант «EPO DOCDB» и вариант «открытые
данные Роспатента» не заменяют друг друга, а дополняют.** Решение владельца
«используем все источники» (РЕШ-55) подтверждено замером, а не соображением:
без российского источника патентная линия по РФ пуста, сколько бы DOCDB ни
качали.

Оговорка, которую нельзя опускать: измерена **дельта одной недели** типа
«Cr-Del». Полное покрытие RU в историческом бэкфайле этим замером не
опровергнуто — но проверить его дёшево нельзя: бэкфайл нарезан на 162 тома по
1,4–1,5 ГБ **не по странам** (`docdb_xml_bck_202607_031_D.zip` и т. п.), то есть
выборочная проверка по RU невозможна без загрузки томов. Что достоверно: в
текущем еженедельном потоке России практически нет.

## Что это значит для объёма (РЕШ-55 п. 2: потолок ~9 ГБ)

Недельная поставка — ~170 МБ. Год еженедельных поставок front file ≈ **8,8 ГБ**,
то есть ровно в оговорённый потолок 9 ГБ. За эти 9 ГБ получаем свежий год
мировой библиографии с рефератами по CN, US, EP, WO, JP, DE, FR, GB — 99 %
документов с рефератом, у части ещё и английский перевод.

Отдельно замечено: у front file **два потока** поставок, по 33 каждый —
`Cr-Del` (создание и удаление) и `Amend` (изменения). Замерен только первый.
Загрузчик обязан брать оба, иначе правки к записям потеряются.
