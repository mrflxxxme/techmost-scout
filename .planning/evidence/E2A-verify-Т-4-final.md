## Расширенный перехват не спрятал нужную ошибку

Предупреждение пишется **фактически** — замер вывода логгера:

```
WARNING app.search.cyberleninka: справочник наборов …\sets.yaml не прочитан:
        'utf-8' codec can't decode byte 0xd1 in position 2
INFO    app.search.cyberleninka: отрасль агропромышленный комплекс → набор rsci
        (запасной, в справочнике не нашлась)
РЕЗУЛЬТАТ: rsci
```

Перехват накрывает ровно два вызова — чтение файла и разбор YAML;
`get_settings().data_dir` вычисляется **до** `try`, поэтому отказ настроек мимо
него не пройдёт. Перебор форм поломки:

```
корень — список                    -> rsci + WARNING «не похож на словарь»
пустой файл                        -> rsci + WARNING «не похож на словарь»
значение с двоеточием без кавычек  -> rsci + WARNING «mapping values are not allowed here»
справочник в cp1251                -> rsci + WARNING с текстом UnicodeDecodeError
```

## Н-1 · находка сверх заявленного: остаток по П-2 (не блокирующая)

Обход структуры справочника идёт **вне** `try`. Если список подменён скаляром,
`TypeError` уходит наружу:

```
sets — скаляр (sets: 5)   !! НЕПЕРЕХВАЧЕНО: TypeError 'int' object is not iterable
keywords — скаляр         !! НЕПЕРЕХВАЧЕНО: TypeError 'int' object is not iterable
```

Сквозной замер последствия:

```
WARNING: источник cyberleninka не собрался: 'int' object is not iterable
БЕЗ отрасли: [arxiv, crossref, cyberleninka, openalex, semanticscholar, showcase, yandex_search]
С отраслью : [arxiv, crossref,               openalex, semanticscholar, showcase, yandex_search]
ПОТЕРЯНО   : ['cyberleninka']
```

Механизм тот же, что в П-2: источник исчезает из сборки, не получает задачу, не
попадает в `failed` и **не попадает в `sources_unavailable`** — в клиентском
отчёте его нет вовсе.

**Почему не блокирует.** Аудит перечислил проверенные им формы поломки;
скалярных среди них не было, так что это новый остаток того же класса, а не
невыполненная правка. Достижимость ниже: cp1251 возникает **без намерения** и
невидим в диффе, тогда как подмена списка скаляром — активная структурная
правка, видимая в диффе и ловящаяся двумя закоммиченными тестами. Критериев
приёмки не задевает. При этом строгое чтение формулировки «**любая** поломка»
им не удовлетворено — зафиксировано прямо.

## Независимое суждение по размену «горн»

Ложные срабатывания подтверждены собственным замером. **Согласен с
классификацией ревью «совет, не блокирующее»**, обоснование своё:

1. **Ни один критерий приёмки не затронут.** Критерий 1 перечисляет конкретные
   отрасли, горнолыжного туризма среди них нет; критерий 3 идёт на нефтегазе,
   агропроме и фарме — 3 из 3 при требуемых 2 из 3, запас разменом не съедается.
2. **Ущерб ограничен устройством размена.** Ошибочная отрасль получает
   предметный набор вместо `rsci`, но `rsci` — не предметный набор, а признак
   уровня издания; по докстрингу адаптера и по живым прогонам он и так даёт
   ноль. То есть размен **заменяет один почти пустой исход другим почти
   пустым** — это не порча работающего поведения, а перестановка внутри
   неработающего.
3. **Порядок записей гасит худший случай.** `georef` идёт последним, выигрывает
   первая подошедшая примета, поэтому «горно-химическая промышленность» уходит
   в `cas` по более ранней примете. Размен не может увести отрасль из
   **правильного** предметного набора — только из запасного.
4. Карточка задачи прямо объявляет исход «кандидатов ноль» не провалом.

Сужение приметы — правка в одну строку, обратимая; уместна отдельной мелкой
задачей, а не возвратом Т-4 на новый цикл при исчерпанных двух циклах ревью.
