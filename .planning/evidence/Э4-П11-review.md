исполнителя.

## Признак видимости — один расчёт

`grep -rn "REJECT\|\.evidence" backend/app/export backend/app/verdicts.py`:
единственное место, решающее видимость, — `verdicts._kept_positions`
(reject всегда, `require_evidence` — опционально). `pdf.py`/`docx.py` больше
не содержат своего `[card for card in report.cards if card.evidence]` —
проверено чтением обоих файлов целиком: печатают `view.client_report`,
собственного фильтра нет. `export/view._comparison_table_hidden` считает
через `verdicts.visible_position_count` — тот же проход, не копия.

Третья копия условия — `web/routes/review.py::_hidden_reason` (не в списке
файлов задачи, экран ревью не должен меняться, РЕШ-205). Сравнил построчно:
`_hidden_reason` — «reject → причина; иначе пустой evidence → причина; иначе
None» — логически совпадает с `require_evidence=True` веткой
`_kept_positions` дословно. **Сегодня не расходится.** Это риск на будущее
(дублирование логики в третьем месте), не блокирующее — задача и инструкция
ревью явно говорят блокировать только при фактическом расхождении сейчас.
Исполнитель сам обозначил это в `notes` handoff, не спрятал.

## `ExportView.client_report` — дефолт `None` + `__post_init__`

Проверил эмпирически (не только чтением): собрал `ExportView(report=...,
card_ids={})` без явного `client_report` (ровно то, что делают
`tests/test_export_pdf.py`/`test_export_docx.py` — все их тесты идут через
этот дефолт) с одной карточкой без `evidence` и одной с — `client_report`
корректно отфильтровал бессылочную карточку и её строку сравнения. Затем
поставил мутацию d) `__post_init__` подставляет `self.report` без фильтра —
8 тестов немедленно покраснели (`test_export_pdf.py`,
`test_export_docx.py`). В боевом коде `client_report` конструируется только
внутри `export/view.py:194` (`build_export_view`), которая всегда передаёт
уже посчитанный `client_visible` явно — единственный производственный путь
конструирования `ExportView` найден `grep -rn "ExportView(" backend/app`
(один результат). Дефолт — безопасный запасной путь только для прямых
тестовых конструкций, не тихий откат старого поведения.
