## Проверка по существу

**Батчинг.** `test_обход_идёт_батчами_по_50_с_паузой_между_ними`: 120 DOI → 3
батча и **2** паузы (не 3), `BATCH_SIZE == 50`, `route.call_count == 120`,
`len(patches) == 120`.

**Патч не перезаписывает непустые поля** — проверено на трёх полях сразу:
`org` («НИИ нефтехимии» не заменяется на «Институт катализа СО РАН»), `snippet`
(«[проверенный партнёр]…» сохраняется), `pdf_url` (собственная ссылка
кандидата остаётся). `cited_by_count` полем `Candidate` не является, поэтому
вопрос перезаписи для неё не встаёт.

**`pdf_url` и `cited_by_count` в патче** —
`test_патч_несёт_организацию_аннотацию_pdf_и_цитируемость`:
`patch["pdf_url"] == "https://example.org/full-text.pdf"`,
`patch["cited_by_count"] == 42`.

**Без ключа — без вызова сети.** Проверено именно **отсутствие обращения**, а
не только пустой результат: `patches == {}` **и** `route.call_count == 0`, плюс
лог содержит «нет OPENALEX_API_KEY».

**`search()` запрещён** — `pytest.raises(NotImplementedError)`.

**Транспортный отказ** — три теста: 429, 500 и нечитаемое тело при коде 200,
все поднимают `SearchError`.

**404 не отказ** — `test_работы_нет_в_каталоге_это_не_отказ`: работы нет в
каталоге OpenAlex → `enrich_by_doi([DOI]) == {}`, это успешный ответ источника,
а не поломка, и остальной батч он не гасит.

**Цитируемость — четыре теста.** Известная даёт «Цитирований: 137»;
неизвестная строки не создаёт; **ноль даёт «Цитирований: 0», а не исчезает** —
отсутствие числа и ноль остаются разными вещами; цитируемость достаётся своему
кандидату по ключу дедупликации, а не соседнему.

**Источник обогащения не попадает в `sources_unavailable`.** Сквозной тест:
`outcome.unavailable == []` — источник обогащения не выдан за отказавший поиск.
Механика закрывает реальный путь, а не только тестовый: пропуск стоит в
`gather_candidates` до итерации по формулировкам плана.
