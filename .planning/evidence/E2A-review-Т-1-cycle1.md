## Урок для процесса (оркестратор)

сообщение вместо деливерабла. Постановка задачи проверяющим ролям впредь должна
содержать строку прямо: **до оркестратора доходит только финальное сообщение,
промежуточные не передаются**. Формулировка «отдавай частями по мере готовности»
(§13) без этой оговорки читается агентом как разрешение оставить итог в
середине.
