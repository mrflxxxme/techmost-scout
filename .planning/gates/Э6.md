# Ворота этапа 6 «Рынок»

Этап 6 — рыночный режим Скаута: вид решения в брифе, зарубежные и российские
аналоги, фильтр стран «Бизнес / Гос», публичный экспресс-скан, деплой через Actions.
План — РЕШ-266 и дополнения РЕШ-277, РЕШ-285, РЕШ-291; грилл — РЕШ-252…265,
РЕШ-271…278. Сборка: облачная сессия-оркестратор 21–22.10.2026, ветка интеграции
`claude/sleepy-planck-11w8jv` (PR #19 стопкой над #18).

Порог без ссылки на доказательство не считается пройденным (§8).

## Условия, зафиксированные заранее

* **Живых вызовов моделей и Яндекса в этапе нет — расход 0 ₽.** Ключи DeepSeek, YandexGPT
  и Яндекс Поиска недействительны (HTTP 401, проверено `scout doctor` 21.10, РЕШ-271);
  все внешние вызовы в тестах — respx и заглушки (инв. 7). Живой скан — DLG-Э6-1.
* **Демона Docker в среде нет** — контейнерный прогон `python:3.12-slim` (РЕШ-249)
  заменён CI GitHub на ветке интеграции (Ubuntu, Python 3.12; РЕШ-276).
* **Сервер из облака недоступен** (прокси пропускает только HTTPS) — деплой только
  через Actions (РЕШ-272), живой запуск — DLG-Э6-3.
* Тексты клиенту приняты в редакции исполнителей (РЕШ-275) — список ниже, правка
  после показа.

## Тексты клиенту (РЕШ-275, на просмотр)

Плашка «Автоматический обзор, не проверен экспертом»; «не найдено»; «[контакт скрыт]»;
форма «Опишите задачу — найдём решения за несколько минут», виды «Продукт / Цифровое
решение / Бизнес-модель / Не знаю», кнопка «Получить обзор»; отказы «Сейчас готовится
другой обзор…», «С вашего адреса сегодня уже запущено максимальное число обзоров…»,
«Бесплатный обзор недоступен: лимит на сегодня исчерпан…», «Обзор не получился…»;
заявка «Нужен полный отчёт?» / «Заказать полный отчёт»; вердикт аналога «Записать
вердикт по аналогу», «Решение по аналогу». Белый список доменов аналогов — 27
(`backend/app/reference/analog_sources.yaml`), реестры РФ — 3; имена ПО — 49
(`software_names.yaml`). Полные списки — handoff задач.
