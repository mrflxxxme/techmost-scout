# Ворота этапа 3 «Интерфейс»

Шапка написана **до** воротного прогона (РЕШ-76). Критерии — из закреплённого
плана (намётка ворот, PLAN.md) и РЕШ-187; ни один не переопределяется после
того, как прогон даст числа. Порог без ссылки на доказательство не считается
пройденным (§8).

## Условия прогона, зафиксированные заранее

* Единственный живой прогон этапа — **через веб-интерфейс**, от формы до
  страницы отчёта (не через CLI). Отрасль — **фармацевтика** (третья отрасль
  протокола приёмки §8; нефтегаз и агропром пройдены на этапе 2).
* Запускает оркестратор: сервер поднимается с печатью `app.__file__` и
  активных параметров (модели, маршруты, резерв, стоп-кран); все живые
  запуски — с `env -u` устаревших переменных (инцидент прогонов Э2-Ж).
* Потолок этапа — **35 ₽** (РЕШ-187), стоп-кран запроса —
  `COST_LIMIT_RUB_PER_REQUEST=20`. Право на второй прогон при отказе первого
  по внешним причинам (429 у Semantic Scholar/OpenAlex с общего IP —
  заранее named-ожидание, их молчание провалом не считается, но обязано
  честно стоять в «Ограничениях этого поиска»).
* Расход этапа до прогона — **0 ₽**: все 14 задач приняты на подменах,
  платных вызовов не было (подтверждается отчётами ревью и верификаций).
* Клиентские фразы новых экранов завизированы владельцем до прогона
  (список — `evidence/E3-фразы-для-визы.md`, виза — записью в DECISIONS).

## Критерии

| № | Порог | Доказательство | Итог |
|---|---|---|---|
| 1 | Путь в браузере пройден целиком: форма → вопросы → бриф с правкой → «Начать поиск» → прогресс → страница отчёта; снимки пяти экранов | | |
| 2 | События SSE шли: в записи потока видны стадии и `done`; keepalive держит паузу ≤ 2 с | | |
| 3 | Отчёт отрендерен из БД: `requests.report_json` непуст, страница открывается по прямой ссылке после перезапуска процесса | | |
| 4 | Стоимость названа: сумма в событии `done`, та же в `requests.cost_rub` и на хабе | | |
| 5 | Пометка «ЧЕРНОВИК — не проверено экспертом» на странице есть | | |
| 6 | Правка карточки сохраняется после перезагрузки; `report_json` не изменился | | |
| 7 | Карточка с пустым `evidence` несёт красную плашку (или случай не наблюдался — тогда ссылка на тест И-12) | | |

## Заранее named-ожидания

* Semantic Scholar и OpenAlex-поиск с общего IP дают 429 — молчание не
  провал, но обязано быть видно в блоке «Ограничения этого поиска» и на
  прогрессе (критерий волны Э2-Ж наследуется).
* Фарма — новая отрасль без накопления в БД: выдача может быть скромнее
  агропрома/нефтегаза; порог «5–7 карточек» здесь не критерий ворот этапа
  интерфейса (он — приёмка пайплайна, пройдена на этапе 2), но число
  карточек фиксируется в доказательствах.
