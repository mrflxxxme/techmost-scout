## Отступление от процесса, действующее в этой сессии

Сессия открыта в каталоге `DBH`, а не в репозитории, поэтому команды `/team-*`
и шесть ролей из `.claude/agents/` не зарегистрированы: агенты запускаются
универсальными с чтением файла роли. Для исполнителей потери нет. У
проверяющих ролей нет инструментального запрета Write/Edit — он заменён
проверкой оркестратора: после каждой проверяющей роли рабочая копия обязана
быть чистой по `git status`. Проверено по всем шести ролям — чисто.

Вторая особенность: до оркестратора доходит **только финальное сообщение**
подагента. Четыре агента закончили работу отсылкой на своё промежуточное
сообщение, и деливерабл терялся; трое отдали текст по повторному запросу,
отчёт ревью Т-1 восстановлен оркестратором по handoff с пометкой отступления.
В постановку проверяющих ролей теперь вписывается это правило прямо.
