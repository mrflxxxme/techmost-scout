Дай владельцу сводку по состоянию проекта. Ничего не меняй: эта команда только
читает. Файлы состояния не обновляются, агенты не вызываются.

Прочитай в этом порядке (§13 `docs/team/CONVENTIONS.md`):
1. `.planning/STATE.md` — где мы и что дальше;
2. `.planning/PLAN.md` — задачи текущего этапа и их состояние;
3. последние 3–5 записей `.planning/JOURNAL.md` — не файл целиком;
4. все файлы `.planning/gates/*.md`, кроме `README.md` — ради строки статуса
   подписи;
5. `.planning/DECISIONS.md` — только чтобы назвать последние решения, без
   пересказа.

Дополни картину инструментами, а не памятью: `git status --short`,
`git log --oneline -5`, `git branch --show-current`. Расхождение между STATE.md и
фактом в git — это находка, о ней надо сказать прямо, а не сглаживать.

Если какого-то файла нет или он пуст — так и скажи, не додумывай состояние.

Выведи ровно шесть блоков, коротко, деловым языком, без пересказа транскрипта:

**Где мы.** Текущий этап по `docs/SPEC.md` и его шаг цикла (0 грилл … 7 ворота).
Ветка, есть ли незакоммиченные изменения.

**Задачи этапа.** Из `PLAN.md`: id, короткое название, состояние (закрыта, в
работе, не начата). Если `PLAN.md` относится к другому этапу, чем STATE.md, —
назови это расхождением.

**Что дальше.** Одна следующая задача или шаг и команда, которой он запускается:
`/team-grill <этап>`, `/team-plan <этап>`, `/team-build <id>`, `/team-gate <этап>`.

**Что ждёт владельца.** Раздел «Задачи владельца» из `STATE.md` плюс
отложенности `DLG-N` из файлов ворот: что именно сделать и где (ссылка на пункт
`docs/deps-manual.md`). Что из этого блокирует следующий шаг, а что нет.

**Ворота.** Таблица: этап, статус подписи, число порогов без доказательства.
Неподписанные ворота перечисляй явно, даже если по ним всё собрано.

**Последнее из журнала.** Две-три строки: что сделано в последнем этапе и какой
урок зафиксирован. Уроки важнее хронологии — они основание для новых инвариантов.

Если по прочитанному видно нарушение процесса — план переписан на ходу, ворота
подписаны без доказательств, задача закрыта без верификации — назови это
отдельной строкой «Замечание по процессу» в конце.
