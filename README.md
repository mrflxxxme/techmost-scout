# ТехМост Скаут

Внутренняя система компании «ТехМост»: по обезличенному описанию
технологической задачи промышленного заказчика находит 5–7 вариантов научных
решений разной зрелости и оформляет карточки с подтверждениями из
первоисточников. Черновик валидирует научный эксперт — только после этого
отчёт уходит клиенту.

- Спецификация для разработки: [docs/SPEC.md](docs/SPEC.md)
- Правила работы агентов в репозитории: [CLAUDE.md](CLAUDE.md)
- Что нужно донести вручную (ключи, регистрации): [docs/deps-manual.md](docs/deps-manual.md)

## Быстрый старт

```powershell
# 1. Окружение
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"

# 2. Ключи: перенос из проекта TEAMLY_RU (значения не выводятся на экран)
.\.venv\Scripts\python.exe scripts\import_keys.py

# 3. Проверка: ключи, модели, источники
.\.venv\Scripts\scout.exe doctor

# 4. Первый запрос
.\.venv\Scripts\scout.exe run "описание технологической задачи" --no-interactive
```

Отчёт появится в `out/`. Веб-интерфейс: `scout serve` → http://127.0.0.1:8000
(логин и пароль — `WEB_AUTH_USER` / `WEB_AUTH_PASSWORD` из `.env`).

## Как это устроено

```
текст задачи → уточняющие вопросы → бриф
    → план поиска (формулировки на русском и английском)
    → параллельный опрос источников:
        витрина партнёров (приоритет) · Crossref · КиберЛенинка · arXiv ·
        Semantic Scholar · Роспатент* · Яндекс-поиск* · OpenAlex*(обогащение)
    → склейка дублей → оценка по 5 критериям → отбор
    → карточки решений (каждый факт со ссылкой) → проверка утверждений
    → сводка и рекомендация → отчёт (markdown / веб / PDF*)
```

Звёздочка — этапы 2–4 спецификации.

Модели: массовые стадии — GigaChat (бесплатный тариф, 250 млн токенов),
качественные — DeepSeek V4-Flash, резерв — YandexGPT. Маршрутизация — строкой
`LLM_STAGE_ROUTES` в `.env`. Ожидаемая себестоимость запроса — единицы рублей.

## Команды

| Команда | Что делает |
|---|---|
| `scout doctor` | Проверка ключей, моделей и источников — с неё начинать любой разбор |
| `scout run "…"` | Полный проход: вопросы → поиск → отчёт в `out/` |
| `scout serve` | Веб-интерфейс |
| `scout showcase файл.csv` | Загрузка витрины разработок партнёров |
| `pytest` | Тесты (без сети: внешние вызовы подменены) |
| `ruff check .` | Линтер |

## Структура

```
backend/app/
  schemas.py      контракты данных пайплайна (pydantic)
  config.py       настройки; имена переменных совпадают с TEAMLY_RU
  models.py       таблицы БД (SQLite)
  llm/            провайдеры моделей и маршрутизатор со стоп-краном по цене
  search/         адаптеры источников; отказ источника не роняет запрос
  pipeline/       чистые стадии + оркестратор
  export/         отчёты: markdown готов, PDF и DOCX — этап 4
  web/            FastAPI + Jinja + HTMX, дизайн-система в static/theme.css
prompts/          промпты стадий; правка = запись в CHANGELOG.md
data/             gov_support.yaml — справочник господдержки; scout.db
docs/             SPEC.md, deps-manual.md, sources.md
tests/            все тесты работают без сети и без ключей
```
